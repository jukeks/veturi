# veturi
Viewstamped Replication library


## Protocol Glossary
* Primary = leader
* Backup = follower
* View = term
* View change = election
* Recovery = node rejoing to group
* Replica group = cluster
* Quorum = f + 1 nodes out of 2f + 1 nodes
